## Descripción

Sistema automático de llenado de botellas desarrollado como proyecto
académico de automatización industrial.

El sistema integra un PLC Siemens S7-1200, un Arduino, válvulas y una celda
de carga para controlar y supervisar el proceso de llenado.

## Tecnologías y componentes

- PLC Siemens S7-1200.
- Arduino.
- Celda de carga.
- Válvulas de control.
- Sensores de presencia o posición.
- Programación Ladder.
- Automatización industrial.

## Funcionamiento general

El sistema detecta la presencia de la botella, activa la etapa de llenado y
utiliza la medición de peso para controlar la cantidad de líquido
suministrada. Al alcanzar el valor establecido, se detiene el llenado y el
sistema queda preparado para el siguiente ciclo.
